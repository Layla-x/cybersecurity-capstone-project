# Final Project: Cyber Mini-Defense Toolkit

## Project Overview

This project uses a cybersecurity login dataset to identify suspicious login activity. The toolkit demonstrates basic cybersecurity tools and analysis techniques.

## Dataset Used

`cybersecurity_login_dataset.csv`

## Tools Included

- Login dataset analysis
- Suspicious activity detection
- Password hashing tool
- Caesar Cipher encryption/decryption tool
- Basic phishing detector
- Optional AI-based anomaly detection

## How to Run the Notebook

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the `cybersecurity_login_dataset.csv` file.
3. Run the notebook cells from beginning to end.

The project demonstrates foundational cybersecurity skills including password security, encryption, log analysis, phishing awareness, and AI-assisted threat detection.
